Write firmware to a Tab5

Pick a size, connect the Tab5 with USB-C, and write it from this page. Needs Chrome or Edge on a computer (Web Serial).

1. Choose a size

Each size is built from the same sources with a different set of optional modules (see the module list). The smaller sizes leave the other features out.

The firmware files are not published here yet. They are built by GitHub Actions and added to this site; try again after the next build.

2. Connect

This browser has no Web Serial. Use Chrome or Edge on a computer.

The browser asks which port to use, so the right COM port is the one you choose in its list. Ports of Espressif USB devices (VID 303A) are the Tab5 or other ESP32 boards. After connecting, the chip is read back and checked.

3. Write

It writes the bootloader (0x2000), the partition table (0x8000) and the application (0x10000), and verifies each by MD5. It does not erase the whole flash and does not touch the ESP32-C6 (Wi-Fi) firmware. Settings that live in other partitions are kept. Do not unplug the Tab5 while it writes.






Recovery


If the Tab5 does not start after writing, connect it again and write another size. The ROM bootloader of the ESP32-P4 stays available, so a failed write cannot make the board unrecoverable.
